# Brilliant Gibran — Software Engineer & Creative Developer

Personal portfolio and interactive engineering showcase built with modern WebGL procedural shaders, clean typography, and high-performance frontend architecture.

---

## 🌟 Key Highlights

- **Procedural Shader Canvas**: Real-time WebGL ambient background rendering with custom GLSL fragment shaders.
- **X-Ray Architecture Mode**: Interactive technical inspector (press `X`) displaying live grid systems, performance telemetry (FPS, LCP, CLS), and design tokens.
- **Zero-Dependency Core**: Self-hosted typography, modular vanilla JavaScript architecture, and optimized vector assets.
- **Accessibility & Performance**: Dark-first palette, reduced-motion compatibility, and sub-second load times.

---

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, Modern CSS3 (Custom Properties & Fluid Typography), Vanilla JavaScript (ES6+ Modules)
- **Graphics**: WebGL, GLSL Shaders
- **Deployment**: Vercel Edge Network with hardened HTTP security headers

---

## 🚀 Getting Started

```bash
# Start local static server
npx serve .
# or
python3 -m http.server 3000
```
